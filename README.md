## Sobre

Atuo com **Engenharia de Dados, Cloud Computing e DevOps**, com foco em criar soluções escaláveis, observáveis e automatizadas. Minha experiência combina construção de pipelines, infraestrutura como código, governança e otimização de ambientes AWS.

Também sou fundador da **CloudStudy**, uma iniciativa independente e open source que organiza o estudo de certificações AWS em português por meio de trilhas, laboratórios, flashcards e simulados.

> Meu objetivo é transformar problemas complexos de dados e cloud em sistemas simples de operar, medir e evoluir.

## Experiência

### Analista de Cloud Jr. · Pixxel

**2026**

Atuação em ambientes AWS com foco em infraestrutura cloud, observabilidade, automação operacional, FinOps, governança e suporte à arquitetura de soluções escaláveis.

### Estagiário DevSecOps · Compass UOL

**2025**

Participação no programa AWS Scholar, com prática em Terraform, pipelines CI/CD, Infrastructure as Code e integração de controles de segurança em ambientes cloud.
